# Saksham Rathore — Software Developer Portfolio

A modern developer portfolio landing page built with React, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## 🚀 Overview
- **Typography**: Kanit (Google Fonts, weights 300–900)
- **Palette**: Dark theme (`#0C0C0C` background with `#D7E2EA` typography)
- **Interactions**: Magnetic cursor follow, sticky stacking project cards, dual-direction marquee, character scroll reveal.

## 🛠 Tech Stack
- **Framework**: React 19, Vite, TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 🌟 Sections
1. **Hero**: Interactive navbar, massive fluid heading, mouse-following magnetic portrait, bio snippet, and contact trigger.
2. **Projects Marquee**: Two scroll-driven rows moving horizontally with seamless loop expansion and project preview tiles.
3. **About Me**: Character-by-character scroll-driven opacity reveal with floating 3D corner assets.
4. **What I Do**: Clean contrast white section detailing core engineering disciplines (Full-Stack, DSA, DevOps & CI/CD, Hackathons, AI-Powered Apps).
5. **Project Cards**: Sticky stacking cards with dynamic scroll scaling (`useScroll` + `useTransform`) and two-column image showcase.
6. **Contact Footer**: Social profile links (Email, GitHub, LinkedIn, YouTube, LeetCode) and copyright.

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/iamsaksham1/Portfolio2.0.git

# Navigate to project directory
cd Portfolio2.0

# Install dependencies
npm install

# Run the development server
npm run dev
```

### Production Build
```bash
npm run build
```
